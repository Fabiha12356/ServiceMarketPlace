# 💜 ServiceMarket

A modern and responsive **Service Marketplace Web Application** where users can create, manage, and explore different services.

The project is built with **HTML, CSS, JavaScript, and Supabase**. It includes authentication, service management, image storage, and a public service-provider section.

---

## 🚀 Features

### 🔐 Authentication
- User Sign Up
- User Login
- User Logout
- Supabase Authentication
- Username stored in user metadata
- User-specific data handling

### 🛍️ Service Management
- Create new services
- Add service category
- Add service description
- Set starting price
- Set delivery time
- Upload service image
- View your own services
- Edit your services
- Delete your services

### 👥 Service Providers
- Browse registered service providers
- View provider name and email
- View services offered by a specific provider
- Public service browsing

### 📱 Responsive Design
- Desktop friendly
- Tablet responsive
- Mobile responsive
- Modern dark and purple UI

---

| Technology | Purpose |

| CSS3 | Styling and responsive design |
